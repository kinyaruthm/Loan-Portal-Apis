# Loan Management System API

A backend **Loan Management System** built with **Java** and **MySQL**, exposing REST APIs to manage members and automate the loan lifecycle from application to repayment.

The system streamlines loan processing and improves workflow tracking and automation.

---

## 🚀 Features
- Member registration and management
- Loan application creation
- Loan eligibility checks
- Loan approval and posting workflow
- Loan disbursement  tracking
- Workflow status transitions with user activity logging

Loan workflow:

NEW → APPROVED → POSTED
---

## 🛠 Tech Stack
- Java (REST APIs)
- MySQL Database
- WildFly / Jakarta EE
- Postman for API testing
